TJ_Youtube_uploader

노래방에서 녹음한 MP3 파일들을 모아 하나의 플레이리스트 영상(MP4)으로 자동 변환하고, 유튜브 채널에 업로드해 주는 데스크톱 자동화 도구입니다.

주요 기능

  • 메타데이터 자동 추출: 파일명의 곡 번호를 기반으로 TJ미디어에서 곡 제목과 가수 정보를 자동으로 스크래핑합니다.
  • 고속 비디오 인코딩: 가독성 높은 텍스트 UI와 그라데이션 효과가 적용된 영상을 1fps로 고속 인코딩하여 생성합니다.
  • 스마트 타임라인: 영상 설명란에 유튜브 챕터(타임스탬프)를 자동으로 생성하여 편리한 감상을 돕습니다.
  • YouTube API 연동: 변환된 영상을 사용자의 유튜브 채널 지정된 재생목록(Playlist)에 안전하게 자동 업로드합니다.

본 애플리케이션은 사용자의 로컬 환경에서만 동작하며, 영상 제작 및 업로드가 완료된 원본 녹음 파일은 로컬에서 즉시 안전하게 삭제(정리)됩니다. 외부 서버로의 데이터 유출이 없습니다.
